## 架构落点（新增部分）

```
src/db/                      数据库契约（Database / DbStatement）与 D1 适配器
packages/runtime-java/       Java 适配器（teavm-javac → RunResponse、错误诊断）
packages/runtime-clang/      WASI 模板模式 + 在线 wasm-clang Worker 两条路径
packages/runtime-shell/      container2wasm 常驻会话与课程 Shell 判题
scripts/containers/         五语言 Alpine 开发镜像、c2w 转换与冒烟脚本
apps/web/public/java/        vendored Java 工件（7.8MB）
apps/web/public/clang/       vendored Clang 工件（28MB，asset-receipts.json）
apps/admin/                 管理面板 SPA；构建同步到 deploy/admin/
scripts/smoke-admin-api.mjs 真实 Wrangler D1 发号/账号/课程烟测
THIRD-PARTY-NOTICES.md       第三方工件许可与校验和
```

数据库层：`src/db/types.ts` 定义 `Database` / `DbStatement` / `DbRunResult`；`src/db/d1.ts` 是唯一的 D1 适配器，`src/index.ts` 把 `env.DB` 包装成 `c.get("db")`。`src/routes` 与 `src/lib` 不再引用 `D1Database` / `D1PreparedStatement`。当前版本未发布，`migrations/0001_init.sql` 与 `db/schema.sql` 是唯一基线，结构变化可直接 `npm run db:reset` 重建，不保留旧数据迁移。

管理端部署落点在 Terre fork（不在本仓库）：

```
.nginx.conf                   admin. / editor. 两个子域 + /api/v1 反代
Dockerfile                    terre2 standalone + origine2 多阶段构建
docker-compose.yml            terre + nginx（可选 cloudflared）
deploy/admin/                 管理面板构建产物（npm run build:admin 生成）
```

用户代码路径遵守 AGENTS.md #4：JS/Python/C++/Java 全部经各自 Worker；Shell 探索与脚本均在
container2wasm 的 vm-worker 真实容器内执行；判题器保持纯函数，不接触运行时。

## 本地运行

```bash
npm install --registry https://registry.npmmirror.com
cp .dev.vars.example .dev.vars          # 填入 TOKEN_PEPPER
npm run db:migrate && npm run dev        # http://localhost:8787
npm test                                 # 所有验收测试
npm run validate:course                  # 课程包校验
```
