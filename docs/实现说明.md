### RPGJS v5 运行时安装边界

- 运行时包已直接固定在根 `package.json`，不再依赖 `@rpgjs/testing` 的传递依赖提供 client/server。
- `@rpgjs/vite@5.0.6` 仅作为开发依赖安装；其 Vite 8 与仓库当前 Vite 6 不混用，现有三个 Vite 配置均未启用 RPGJS 插件。
- 当前编辑器仍导出 Tiled JSON；默认 RPGJS Tiled 路径要求 TMX/TSX。转换器或 `provideLoadMap()` 适配层属于后续 M1a/M6d 工作。
- 依赖安装不等于 Worker 引擎已接入；`createRpgServerWorker()`、Durable Object、`provideMmorpg()`、地图/碰撞/事件与断线重连仍需真实浏览器验收。
- 学生代码继续只在浏览器 Worker 执行；Cloudflare 不接收可执行学生源码。
- 判题目标为双轨并行：五语言 stdio 轨与 RPGJS 世界状态轨。当前 `Stage` 仍按单个 `judge.kind` 二选一，composite/并行聚合尚未实现。
- c2w 只有 Shell/终端接口；文件、进程、端口类 goals 必须写成 shell 探针并判定 stdio/退出码，不能读取结构化容器状态。

## M6d RPGJS 自建地图编辑器最小切片（2026-11-28）

### 实现

- 新增 `apps/editor`（React + Vite）与纯 TypeScript `src/map-model.ts`；不依赖 Terre/WebGAL、RPGJS Studio、后端发布或重型地图库，也不执行用户代码。
- 默认 20 × 15、32px tile；支持新建、宽高调整、清空、示例重置、四种程序化占位图块、画笔、橡皮、矩形填充、碰撞层与事件层。
- 事件支持放置、删除及 `id/name/x/y` 编辑；地图与事件均校验 ID 唯一性、坐标边界和网格对齐。
- Tiled JSON 包含 `width/height/tilewidth/tileheight`、`ground`/`collision` tilelayer、`events` objectgroup、tileset 与 `mapId`。导入严格校验有限正交格式、维度、data 长度、GID/碰撞值范围、tileset 范围、对象坐标和 ID 唯一性，错误接入中英文 i18n。
- localStorage 自动保存/恢复；JSON 文件导入、导出下载；桌面优先布局在 390px 视口无页面横向溢出（画布可在自身容器内滚动）。
- `src/index.ts` 新增同源 `/editor` 与 `/editor/*`：HTML 深层回退到编辑器 index，资源仅从 `/editor/assets` 读取，缺失资源即使遇到 Assets SPA HTML 回退也返回 404；响应带 `codequest-app=editor` 标记验证及 CSP/HSTS/nosniff/Referrer-Policy/X-Frame-Options 等安全头。
- 根脚本新增 `dev:editor`、`build:editor`、`build:editor:embedded`、`test:editor`；根 build/typecheck、Wrangler watch_dir/run_worker_first 与 `.assetsignore` 均已接入。`verify:build` 现在同时校验 admin/editor 的 JS/CSS 引用；`/editor/assets/*` 与 admin 资源一样使用一年 immutable 缓存。
