## 未完成 / 需要拍板

- **M4 container2wasm 容器会话与 loopback 端口 spike**：见 `docs/spike-M3-M4.md`。用户提供 `docker.1ms.run` 镜像源后镜像已拉齐，转换已越过 10/127 步（Go 代理改用 goproxy.cn），转换完成后跑 `scripts/spike-loopback.mjs`。其余 M4 验收项（Bandit 前 5 关、shell 补全、SW 预缓存）已完成。
- **Service Worker 预缓存**：已实现（`apps/web/public/sw.js` 按 clang `asset-receipts.json` / java `manifest.json` 预缓存，`tests/acceptance/sw-precache.test.ts` 校验 SHA-256 一致）；首次访问仍需下载约 36MB，离线/二次进入命中缓存。
- **Java 预编译缓存**（同源码哈希）与 Java 补全（设计仅要求高亮 + 编译诊断，已满足）。
- **M6 可视化管理端 / M7 成就、统计、防作弊回放**：未开始；判题器已有 `replayIsConsistent()` 作为回放基础。
- **JS/TS IntelliSense**、Python pyright-browser 补全：未接入（Monaco 高亮 + 诊断已完成）。

## 架构落点（新增部分）

```
packages/runtime-java/       Java 适配器（teavm-javac → RunResponse、错误诊断）
packages/runtime-clang/      WASI 模板模式 + 在线 wasm-clang Worker 两条路径
packages/runtime-shell/      内存教学 shell（探索）+ wasi-sh（脚本判题）
apps/web/public/java/        vendored Java 工件（7.8MB）
apps/web/public/clang/       vendored Clang 工件（28MB，asset-receipts.json）
scripts/spike-java.mjs       M2.5 真实浏览器 spike
scripts/spike-m3m4.mjs       M3/M4 环境可行性探测
docs/spike-M3-M4.md          spike 报告（含降级结论与待拍板项）
THIRD-PARTY-NOTICES.md       第三方工件许可与校验和
```

用户代码路径遵守 AGENTS.md #4：JS/Python/C++/Java 全部经各自 Worker；shell 脚本由 wasi-sh 在
其自身 Worker 内执行；判题器保持纯函数，不接触运行时。

## 本地运行

```bash
npm install --registry https://registry.npmmirror.com
cp .dev.vars.example .dev.vars          # 填入 TOKEN_PEPPER
npm run db:migrate && npm run dev        # http://localhost:8787
npm test                                 # 所有验收测试
npm run validate:course                  # 课程包校验
node scripts/spike-java.mjs              # Java 真实浏览器 spike（需 firefox）
```
