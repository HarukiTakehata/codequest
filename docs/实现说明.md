## 明确未做（后续里程碑）

- **M3 真正 wasm-clang 在线编译**：资产 60MB+、SW 预缓存与编译错误回填尚未接入；`runtime-clang` 在没有模板 wasm 时返回明确提示，不伪装成功。
- **M4 container2wasm / 进程与端口状态检查**：当前 shell 是内存文件系统，多进程与 loopback 端口检查不在范围内；设计书 §5.5 的 spike 尚未做。
- **M6 可视化管理端**：目前管理端是 API + 手写课程包；WebGAL Terre fork 与自定义引擎打包留待 M6。
- **M7 成就/统计/防作弊回放**：判题器已提供 `replayIsConsistent()` 作为回放基础，但未接后端定时任务。
- **编辑器智能补全**：Pyright-browser、C++ 编译错误行内诊断已预留接口（`setDiagnostics`），JS/TS IntelliSense 需接 TS language worker；当前 Monaco 只做高亮 + 诊断。
- **移动端**：按设计书定位桌面优先，未做只读降级。

## 架构落点

```
src/                        Workers 后端（auth / admin / courses / progress）
migrations/0001_init.sql     D1 schema（users / sessions / courses / progress / batches）
packages/judge/              纯 TS 判题 + goals（前后端共用，R11 回放基础）
packages/runtime-js/         JS Worker（executeJs + worker/client）
packages/runtime-pyodide/    Pyodide Worker（stdin/stdout patch）
packages/runtime-shell/      内存文件系统 + 教学 shell 子集 Worker
packages/runtime-clang/      WASI shim + 模板编译模式 Worker
apps/web/src/engine/         WebGAL 兼容剧本解析与演出引擎
apps/web/src/components/     舞台、工作台、目标清单、判题面板、终端、登录/课程列表
courses/demo/                四语言 + Bandit 式探索的完整演示课程包
scripts/                     课程打包 / 验收脚本
```

用户代码路径遵守 AGENTS.md #4：SPA 只用各 runtime 的 `client.ts` 创建 Worker，
`executeJs/executePython/executeShell/executeCpp` 从不进入主线程；判题器是纯函数，不接触运行时。

## 本地运行

```bash
npm install --registry https://registry.npmmirror.com
cp .dev.vars.example .dev.vars          # 填入 TOKEN_PEPPER
npm run db:migrate                       # 本地 D1
npm run dev                              # 构建前端 + wrangler dev（:8787）
```

首次打开 `/` 会进入初始化向导创建管理员。批量发号示例：

```bash
curl -b admin.cookies -X POST http://localhost:8787/api/v1/admin/accounts/batch \
  -H 'Content-Type: application/json' \
  -d '{"csv":"email,display_name\nalice@example.test,Alice\n"}'
```

上传演示课程：

```bash
node scripts/pack-course.mjs courses/demo /tmp/demo.pack.json
jq -n --slurpfile p /tmp/demo.pack.json '{pack:$p[0]}' | \
  curl -b admin.cookies -X POST http://localhost:8787/api/v1/admin/courses \
  -H 'Content-Type: application/json' --data-binary @-
```

学员用发放表中的初始密码登录，强制改密后可拉取课程并开始剧情。

## 验收证据（2026-11-24）

- `npm test`：6 个测试文件、36 项通过（判题 11、JS 4、Python 4（真实 Pyodide）、Shell 5、C 模板 3、后端 M0 6、剧情 3）。
- `npm run typecheck`：根目录与前端均通过。
- `npm run build`：SPA 构建成功（Monaco 导致主包较大，属 P1 优化项）。
- `npm run validate:course`：演示课程 13 个文件、5 个挑战校验通过。
- 真实 `wrangler dev --local` + curl 冒烟：setup → 批量发号 → 课程上传 → 学员登录 →
  未改密访问课程返回 403 → 改密重登 → 拉课程包与进度 → 未登录访问课程返回 401 → SPA 静态资源 200。
