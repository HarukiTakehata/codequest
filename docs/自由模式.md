# 自由模式（Free Mode）

> 用户 2026-11-25 指定的优先功能：剧情系统可先用占位符，先交付「任选语言自由写代码 + 自定义判题」。
> 本仓库已有兼容 WebGAL 子集的剧情引擎，剧情关照常可用；自由模式与剧情完全解耦。

## 入口与流程

课程列表页顶部「⚡ 自由模式」按钮进入（需登录，课程与草稿都经会话鉴权）。

1. 选语言：JavaScript / Python / Java / C/C++ / Shell 五个页签，各自独立草稿。
2. 编辑代码：Monaco 编辑器，五语言高亮 + 编译错误行内诊断（C++/Java）。
3. 自定义测试点：每个测试点有 `name / stdin / expected / 比对模式`；比对模式复用判题器的
   `exact / eol / ws / regex-line / numeric-tol` 五种（见 `docs/课程包格式.md`）。
4. **运行**：用当前 stdin 调对应运行时，查看 stdout/stderr/exitCode。
5. **提交判定**：逐测试点跑同一份代码，给出加权分与首个失败点的行级 diff。
6. 草稿保存：登录后按 `(user_id, lang)` 存 D1，切页签/下次登录自动读回；未登录访问返回 401。

## 实现落点

| 文件 | 作用 |
|---|---|
| `migrations/0002_freeform.sql` | `freeform_drafts(user_id, lang, code, stdin, testcases_json, updated_at)` |
| `src/routes/freeform.ts` | `GET /api/v1/freeform`（模板 + 全部草稿）、`GET/PUT /api/v1/freeform/:lang` |
| `apps/web/src/components/FreeMode.tsx` | 自由模式主界面（语言页签、编辑器、测试点编辑、运行/判题） |
| `apps/web/src/free.ts` | 自定义测试点 → 统一 `JudgeConfig`（纯函数） |
| `apps/web/src/runners.ts` | 按语言懒加载 Worker；shell 走 wasi-sh，C++ 走 wasm-clang 在线编译 |

## 语言运行时（与剧情关完全一致）

- JavaScript：Worker + `console.log` 劫持 + `readline()` 逐行 stdin。
- Python：真实 Pyodide，`input()`/`print()`。
- Java：`@live-codes/java-wasm`（teavm-javac），Worker 内 javac → TeaVM WasmGC。
- C/C++：`@live-codes/clang-wasm`（Clang 22 → WASM），Worker 内真编译运行；有编译错误时行号回填 Monaco。
- Shell：`wasi-sh`（真实 busybox ash + coreutils wasm），初始 cwd `/home/student`。
