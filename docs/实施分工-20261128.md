## 共同约束

1. 不改 OI 判题器、Shell/c2w 运行时或第三方上游；WebGAL 语法已废除，不再作为兼容约束。
2. 不把 `rpgjs` 伪装成 stdout 语言，不向 `RunRequest/RunResponse` 塞脚本结果。
3. 用户代码只在 Worker/WASM 沙箱执行；主线程与 Cloudflare Worker 不执行学生脚本。
4. 每次 attempt 从不可变 `WorldInit` 新建 `SimWorld`；失败丢弃，禁止真实世界 undo。
5. 编辑器、宿主、判题共用同一 `ApiDescription`；`missingImplementations` 必须为空。
6. 当前课程包仍是 UTF-8 文本包，二进制课程发布与 sealed 分流未完成；不把隐藏 script cases 下发。
7. 通用账号管理包含管理员；成员管理禁止重置本人密码，管理员个人资料自助改密保留；始终至少保留一个活跃管理员。
