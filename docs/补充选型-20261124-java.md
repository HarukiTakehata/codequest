# 补充选型：Java 语言支持（2026-11-24）

> 本文件为设计书（docs/编程学习系统设计书.md v0.2）的补充选型记录，不修改设计书正文。
> 背景：紧急插入需求——系统必须同时支持 Java 语言的学习。设计原则不变：用户代码在浏览器 Worker/WASM 内编译与运行。

## 1. 需求约束

Java 与其他四种语言不同：学生代码需要「源码 → 字节码 → 运行」两步，浏览器内必须同时有 **javac（编译器）** 和 **JVM/等价运行时**。判题还要求 stdin/stdout/exitCode 语义可用。

## 2. 候选核查（2026-11-24）

| 方案 | 机制 | 许可 | 结论 |
|---|---|---|---|
| **teavm-javac 打包（live-codes/java）** | 把 OpenJDK javac + TeaVM AOT 编译器打进**单个 WASM 模块**：源码进 Web Worker → 浏览器内 javac 产出 class → TeaVM 转 WasmGC → 运行 | Apache-2.0（注意内含 OpenJDK javac，见 §5） | ✅ **选定为主方案** |
| ├─ 上游 konsoletyper/teavm-javac | "Java compiler in the browser"，92★，2026-11-22 仍活跃 | 未标注 | ❌ `TConsoleInputStream` 抛 EOF（TeaVM 0.15.0 仍如此），**无 stdin，判题不可用** |
| └─ Vsprocessing/teavm-javac（live-codes 所用 fork） | 补上 console stdin + 更宽的运行时类库 + WasmGC/JS 双后端 | Apache-2.0 | ✅ 以此为实际工件源 |
| **CheerpJ 5.0**（Leaning Tech，2026-11-02 发布） | 完整 OpenJDK（Java 21，Java 25 preview）编译为 WASM 跑在浏览器，可跑 javac | 专有；Community 免费档限个人/教育/爱好用途 + 「Built with CheerpJ」署名，**禁止自托管**（必须从其 CDN 加载） | ⚠️ 备选：功能最强但体量大、许可受限且依赖外部 CDN，与本项目「运行时资产可自托管/离线缓存」原则冲突 |
| **DoppioJVM** | TS 实现的 JVM 8 子集 | 学术项目 | ❌ 多年未维护 |
| **Bck2Brwsr / JWebAssembly** | 字节码 AOT → JS/wasm | Apache-2.0 | ❌ 只解决「运行」，缺浏览器内编译管线，需自拼 javac 方案，无收益 |
| 服务端判题（javac + JVM 沙箱） | 违反设计原则「后端不执行用户代码」 | — | ❌ 仅作理论兜底，不立项 |

**选型结论：采用 live-codes/java 的 teavm-javac 打包（基于 Vsprocessing fork）作为 Java 主运行时**。理由：① 全流程（编译+运行）在浏览器 Worker 内完成，符合设计原则；② 体量小（compiler.wasm 5.2MB + runtime-classlib 2.2MB，合计 ~7.4MB，与 clang wasm 同一量级，Service Worker 预缓存即可）；③ Apache-2.0 主线许可；④ fork 支持 stdin，满足 IO 判题；⑤ 上游三条线（konsoletyper / Vsprocessing / live-codes）2026 年内均活跃，非弃坑项目。

## 3. 集成方案（对齐现有运行时接口）

沿用设计书 §5.1 的统一执行接口，新增 `packages/runtime-java`：

- Worker 内流程：加载 `compiler.wasm`（javac）编译用户源码 → 产出 class → TeaVM WasmGC 运行 → 收集 stdout/exitCode。stdin 由 Vsprocessing fork 的 console 输入注入。
- 资产经 Service Worker 预缓存，与 wasm-clang 同策略（设计书 §9）。
- 编辑器（§6.1）：Monaco 自带 Java 高亮（Monarch）；补全 P0 用关键字 + 模板符号 provider + javac 编译错误回填诊断（与 C/C++ 同款三层兜底）；Java 浏览器内 LSP（如经 CheerpJ 挂 jdt.ls）列为远期观察项，不进排期。
- goals（§6.2）直接复用 `source-regex`（如「包含 `public static void main`」）、`output-contains`、`exit-code`。
- 版本口径：TeaVM 0.14.x（live-codes vendored 工件，scripts 校验和固定），Java 语言级按 fork 支持范围出题并标注。

## 4. 排期影响

不改动设计书里程碑结构：Java 运行时挂接建议排在 M2 之后、与 M3 并行（同为「编译型语言 + SW 预缓存」模式，经验直接复用）；Java 入门章节内容排 M3 后。

## 5. 风险与注意

| 风险 | 对策 |
|---|---|
| live-codes/java 仅 0★、单人维护，fork 依赖 Vsprocessing | 工件按 live-codes 的 `scripts/fetch-teavm.mjs` 方式 vendored + 校验和固定在本仓库；必要时自行维护 fork（放 HarukiTakehata 账号） |
| 内含 OpenJDK javac：编译器工件为 GPLv2 + Classpath Exception，与主仓库 MIT 并存 | 编译器 wasm 作为**独立 vendored 工件**携带原始许可声明，不并入 MIT 代码；用户代码产物不在 GPL 意义上链接运行时 classlib（TeaVM 运行时为 Apache-2.0）；发布时附 THIRD-PARTY-NOTICES |
| WasmGC 需要较新浏览器（Chrome/Edge 已支持） | 与 wasm-clang 一样列入「最低浏览器要求」提示；不影响其余语言 |
| TeaVM classlib 覆盖不全（非完整 JDK） | 出题标注可用 API 范围（与 C/C++「标注可用库」同策略）；后续实测建立白名单 |
| 首次编译延迟（浏览器内 javac） | 出题时限提示放宽；预编译缓存（同源码哈希） |
