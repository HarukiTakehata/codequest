# 管理面板与批量发号（M6.1）

> 设计依据：`docs/编程学习系统设计书.md` §7.1 / §7.3 / §8 M6.1；接口契约：`docs/管理面板API.md`。

## 功能

- 教师/管理员登录/登出与概览统计；学生不显示管理入口。
- CSV 上传、拖拽或粘贴；先预览行数、生成/指定密码数量和邮箱冲突，再确认建号。教师只能创建学生，管理员可创建学生或教师。
- 1–500 个账号原子创建；任一邮箱冲突整批回滚。
- 24 小时一次性发放链接；并发领取只有一方成功；领取后清空 CSV 明文；未领取链接可撤销；管理端读取与每小时 Cron 都会清除过期/撤销批次的明文。
- 学生账号搜索、状态/角色筛选、分页、显示名修改、启停与临时密码重置；教师只能管理学生，管理员还可管理教师和调整角色。
- 课程包 JSON 上传、版本升级、上架/下架；可跳转独立 Terre 编辑器。
- 发号、账号启停/角色变更、密码重置、链接撤销、课程发布/上下架的审计记录；仅管理员可查看。

## 本地运行

```bash
npm install --registry https://registry.npmmirror.com
cp .dev.vars.example .dev.vars          # 填写 TOKEN_PEPPER
npm run db:migrate                       # 应用单一 0001 初始化基线
npm run dev:api                          # Worker API：http://localhost:8787
npm run dev:admin                        # 管理面板：http://localhost:5174
```

首次使用先在学习端 `http://localhost:8787/setup` 创建实例与管理员，再在管理面板登录。管理面板遇到空实例会跳转到该唯一初始化入口，不再重复提供初始化表单；独立子域通过 `LEARNER_URL` 定位学习端。管理员账号不通过批量发号创建；管理员可批量创建教师，教师可批量创建学生。学习端“管理工作台”入口默认指向 `/admin/`，独立子域部署时设置 `ADMIN_URL=https://admin.example.com`。

CSV 模板：

```csv
username,email,display_name,password
alice,alice@example.test,Alice,
bob,,Bob,bob-chosen-password-123
```

- 用户名必填且唯一，邮箱可空；两者均不区分大小写。
- `display_name` 为空时使用用户名。
- 第四列留空时由服务端生成 96 位随机临时密码；指定密码至少 10 个字符，且不能以 `=`、`+`、`-`、`@` 开头（防电子表格公式注入）。
- 初始密码必须首次登录修改；重置密码会撤销该成员的全部会话。

## 构建与发布

```bash
npm run build:admin
# 产物同时位于 apps/admin/dist/ 与 deploy/admin/
npm run build:admin:embedded           # 同源 /admin/ 产物写入 apps/web/dist/admin/
npm run build                            # 学习端 + 管理端 + /admin 嵌入 + c2w worker 补丁
```

`deploy/admin/` 是生成目录，不提交构建产物。nginx 根目录指向该目录，SPA 未知路径回退 `index.html`，`/api/v1/*` 反向代理到 Worker。同源 Worker 部署则使用 `apps/web/dist/admin/`，`/admin` 会跳转到 `/admin/`，`/admin/overview` 等深层路由由 Worker 回退到管理端 HTML，不再回退到学习端。独立子域部署必须配置：

```dotenv
SESSION_COOKIE_DOMAIN=.example.com
ADMIN_URL=https://admin.example.com
EDITOR_URL=https://editor.example.com
LEARNER_URL=https://learn.example.com
```

管理员登录后，HttpOnly、Secure、SameSite=Lax 的 `codequest_session` 以父域 Cookie 下发，供 `admin.` 与 `editor.` 复用。代理 Worker 时使用 HTTPS 上游，确保浏览器收到 Secure Cookie。编辑器子域仍必须按设计书 §7.3 配置 `auth_request` 或 Cloudflare Access。

建议 nginx 配置（证书与上游地址按环境替换）：

```nginx
server {
    listen 443 ssl;
    server_name admin.example.com;
    ssl_certificate /etc/letsencrypt/live/admin.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/admin.example.com/privkey.pem;
    root /srv/codequest/deploy/admin;
    index index.html;
    client_max_body_size 4m;
    proxy_ssl_server_name on;

    add_header X-Content-Type-Options nosniff always;
    add_header Referrer-Policy no-referrer always;
    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
    add_header X-Frame-Options DENY always;
    add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; font-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'none'; form-action 'self'" always;

    # 一次性下载 token 不进入访问日志。
    location ^~ /api/v1/admin/accounts/download/ {
        access_log off;
        proxy_pass https://codequest.example.workers.dev;
        proxy_set_header Host codequest.example.workers.dev;
    }

    location /api/v1/ {
        proxy_pass https://codequest.example.workers.dev;
        proxy_set_header Host codequest.example.workers.dev;
    }

    location / {
        try_files $uri $uri/ /index.html;
        expires -1;
    }

    location /assets/ {
        expires 1y;
    }
}
```

管理面板不在 `localStorage` / `sessionStorage` 保存密码、下载 token 或会话。一次性密码/链接只显示一次，应通过可信渠道分发；不要把带 token 的 URL 粘贴到聊天、工单或分析工具。撤销下载链接不会停用已经创建的账号，需在「账号管理」中另行停用。nginx 示例关闭了下载路径访问日志；生产 Worker 的可观测性/日志导出也应排除或严格限制 `/accounts/download/` 路径，避免 token 进入长期日志。

## 验收

```bash
npm test
npm run typecheck
npm run build
```

后端测试覆盖权限、预览、整批回滚、D1 参数上限、过期/撤销/并发领取、Cron 明文清除、账号启停、重置密码、审计与课程上下架。管理面板浏览器验收脚本为 `npm run test:admin`（需要 Playwright Chromium；可用 `CHROMIUM_PATH` 指定可执行文件）。

真实 Wrangler/D1 烟测只允许空本地数据库，脚本会拒绝非本地地址：

```bash
npx wrangler d1 migrations apply codequest_local --local --persist-to /tmp/opencode/codequest-admin-smoke-db
npx wrangler dev --local --persist-to /tmp/opencode/codequest-admin-smoke-db --port 8787
# 另一个终端：
ADMIN_SMOKE_ALLOW_WRITE=1 npm run smoke:admin
```

该烟测创建 20 个账号，验证真实 D1 参数分块、一次性下载、首次改密、账号启停/重置、课程上下架和审计；成功输出 `ADMIN_API_SMOKE_PASS`。
